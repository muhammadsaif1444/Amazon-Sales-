# 📊 Amazon Sales Dashboard 2024

This Power BI dashboard project showcases an interactive analysis of Amazon's sales performance across India for the year 2024. It provides a detailed breakdown of sales figures, unit distribution, and regional performance to help drive data-driven business decisions.

## 📌 Key Highlights:

- 💰 **Total Sales**: ₹1,02,26,625 across 23 cities
- 📦 **Units Sold**: 33,874
- 🌆 **City-wise Sales Analysis**: Identifies top-performing cities like Delhi with peak sales
- 🌍 **State-wise Sales Distribution**: Visualized using a heatmap for easy regional insights
- 📈 **Product-wise Units Sold**: A funnel chart ranking product categories by units sold
- 📉 **Interactive Visuals**: Dynamic charts and KPIs for enhanced decision-making

## 📂 Tools Used:
- **Microsoft Excel** – for data cleaning, data visualization and dashboard creation


## 🔍 Insights:
- Delhi had the highest city-wise sales.
- Maharashtra topped state-wise sales distribution.
- The top-selling product unit reached **5,267 units**, indicating strong demand.
